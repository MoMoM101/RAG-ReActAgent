## AI 编码工具的使用范围

项目开发过程中使用过 AI 编码助手，包括 Claude Code 和 Codex。AI 工具主要用于：

- 讨论需求和实现方案；
- 生成局部代码草稿或重构建议；
- 补充测试用例、边界条件和故障注入思路；
- 协助排查错误、审查代码和整理文档；
- 生成或维护合成评测夹具。

AI 工具不作为项目作者或独立贡献者。以下工作由开发者本人负责：

- 确定产品范围、架构和技术取舍；
- 选择、修改、集成并审查进入仓库的代码；
- 配置并运行真实开发环境；
- 处理安全、数据一致性、迁移和恢复风险；
- 设计评测标准、检查结果并决定发布；
- 对代码、文档、许可证和最终行为承担责任。

仓库不主张每一行代码均由人工逐字键入；同样，也不把未经审查的模型输出视为完成的实现。AI 辅助内容只有经过集成检查、自动化测试或人工验证后才应进入正式版本。

## 由开发者主导设计的核心模块

当前版本的主要设计与集成工作包括：

1. 文档上传、解析、切片、OCR 等待、索引和失败恢复生命周期；
2. Qdrant 语义检索、SQLite BM25、加权 RRF、去重和可选 Reranker 的混合检索链路；
3. ReAct 工具循环、查询消歧、上下文预算、循环收敛和流式输出；
4. 基于证据的引用、数字一致性、拒答和回答修复机制；
5. SQLite、文件、Qdrant 与 BM25 之间的数据一致性策略；
6. JWT、Refresh Cookie、密码变更失效和基础权限边界；
7. 数据库迁移、备份恢复、任务重试和重启恢复；
8. 合成评测数据、稳定 qrels、回答质量门禁和发布门禁。

这里的“主导设计”表示开发者对需求、边界、实现选择和最终集成负责，不表示开发过程没有使用开源依赖、参考资料或 AI 辅助工具。
